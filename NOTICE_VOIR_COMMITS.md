# Voir mes commits sur GitHub (depuis le mobile ou ailleurs)

## Depuis le navigateur (mobile ou ordinateur)

1. Ouvre **github.com** dans ton navigateur.
2. Connecte-toi à ton compte GitHub (si ce n’est pas déjà fait).
3. Va sur ton dépôt **BonKont** (ou tape dans la barre d’adresse :  
   `github.com/GeorgesCod/BonKont`).
4. Sur la page du dépôt, clique sur le lien **« X commits »**  
   (à côté du nom de la branche, souvent `main` ou `master`).
5. Tu vois la liste de tous les commits : message, auteur, date.  
   Clique sur un commit pour voir les fichiers modifiés.

---

## Raccourci

- Lien direct vers les commits du dépôt BonKont :  
  **https://github.com/GeorgesCod/BonKont/commits/master**  
  (remplace `master` par `main` si ta branche s’appelle `main`).

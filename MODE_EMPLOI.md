# Mode d’emploi BONKONT

**Les bons comptes font les bons amis.**

Ce guide décrit comment utiliser BONKONT au quotidien : en tant qu’**organisateur** ou en tant que **participant invité**.

---

## 1. Qu’est-ce que BONKONT ?

BONKONT permet de gérer les dépenses partagées d’un événement (voyage, soirée, pot commun, etc.) :

- **Organisateur** : crée l’événement, partage un code à 8 lettres, valide les participants, enregistre les transactions et gère la clôture.
- **Participant invité** : rejoint l’événement avec le code, voit ses transactions et peut gérer son événement (transactions, clôture) comme l’organisateur.

Chacun voit uniquement les événements auxquels il a accès (ceux qu’il organise ou ceux où il est participant accepté).

---

## 2. Démarrer

### Connexion

1. Ouvrez BONKONT dans votre navigateur (ou l’application déployée).
2. Cliquez sur **« Se connecter »**.
3. Renseignez **nom** et **email**, puis validez.

### Tableau de bord

- Une fois connecté, cliquez sur **« Tableau de bord »** (ou allez à la page d’accueil puis « Tableau de bord »).
- Vous voyez la liste de **vos événements** :
  - ceux que vous **organisez** ;
  - ceux où vous êtes **participant accepté** (événement rejoint avec un code).

Vous ne voyez pas les événements des autres utilisateurs.

---

## 3. En tant qu’organisateur

### Créer un événement

1. Tableau de bord → **« Créer un événement »**.
2. Renseignez : titre, description, dates, budget (montant total ou par personne), nombre de participants, etc.
3. Validez la création.
4. Un **code à 8 lettres** est généré (ex. `HTKNDVHT`). C’est le code de l’événement.

### Partager l’événement

- **Code** : communiquez le code en 8 lettres (ex. par message, mail).
- **Lien** : vous pouvez partager un lien du type :  
  `https://votre-site/#/join/HTKNDVHT`  
  (remplacez `HTKNDVHT` par le vrai code).
- **Inviter des amis** : utilisez le bouton « Inviter des amis » pour copier le lien ou le code.

Important : le code doit être saisi **en entier** (8 lettres). Si on ne met que 3 lettres (ex. `HTK`), l’événement ne sera pas trouvé.

### Valider les participants

1. Les personnes qui rejoignent avec le code envoient une **demande de participation**.
2. Dans la gestion de l’événement, vous voyez les demandes **en attente**.
3. **Acceptez** ou **refusez** chaque demande.
4. Une fois acceptée, le participant a accès à l’événement (tableau de bord, transactions, clôture).

### Gérer l’événement

Depuis le tableau de bord, sur la carte de l’événement :

- **Gérer l’événement** : vue principale (participants, infos, rappels).
- **Transactions** : ajouter dépenses, avances, contributions au pot, transferts, remboursements.
- **Gérer la clôture événementielle** : soldes, qui doit quoi à qui, export PDF si disponible.
- **Enregistrer un paiement** : enregistrer un paiement (carte ou espèces) pour un participant.
- **Scanner un ticket** : scanner un ticket CB pour enregistrer une dépense (si activé).
- **Envoyer un rappel** : rappel de paiement par email/SMS (si configuré).
- **Supprimer** : supprimer l’événement (à utiliser avec précaution).

---

## 4. En tant que participant invité

### Rejoindre un événement

1. Cliquez sur **« Rejoindre »** (menu ou lien reçu).
2. Saisissez le **code à 8 lettres** (ex. `HTKNDVHT`) dans le champ « Code événement ».
   - Saisissez **les 8 lettres** : une recherche n’est faite qu’à partir de 8 caractères.
   - Puis cliquez sur **« Rechercher »** (ou attendez la recherche automatique).
3. Si l’événement est trouvé : titre, description, budget s’affichent.
4. Si demandé, **connectez-vous** (nom + email).
5. Vérifiez pseudo et email, puis cliquez sur **« Rejoindre l’événement »**.
6. Votre demande est envoyée ; l’organisateur doit **accepter** votre participation.

### Après acceptation

- Vous recevez l’accès à l’événement (selon la configuration de l’app).
- Dans le **tableau de bord**, vous voyez **uniquement** cet événement (ou vos autres événements organisés / invités).
- Vous pouvez :
  - **Gérer l’événement** : voir les infos, les participants.
  - **Transactions** : voir et gérer les transactions comme l’organisateur (selon les droits).
  - **Clôture** : voir les soldes, qui doit quoi à qui.

L’événement invité reste affiché au tableau de bord même après un changement de page ou un rechargement (tant que vous restez connecté et que l’événement n’est pas supprimé).

---

## 5. Tableau de bord et navigation

### Onglets

- **En cours** : événements actifs ou ouverts.
- **En attente** : événements en attente.
- **Terminés** : événements clôturés.

### Sur chaque carte d’événement

- **Titre**, **description**, **code** (visible pour l’organisateur, masqué pour l’invité).
- **Boutons** : Gérer l’événement, Transactions, Clôture, Enregistrer un paiement, etc.
- En cliquant sur le **code** (ou « Gérer l’événement »), vous ouvrez la vue de gestion de cet événement.

### Retour

- Le bouton **flèche Retour** (ou « Retour ») vous ramène au tableau de bord (liste des événements) ou à la vue précédente.

---

## 6. Règles importantes

### Code à 8 lettres

- Chaque événement a un **code unique de 8 lettres** (ex. `HTKNDVHT`).
- Pour rejoindre ou rechercher un événement, il faut **saisir les 8 lettres**.
- Ne pas tronquer le code (ex. `HTK` seul ne suffit pas).

### Règle BONKONT (en bref)

- **Validation** : toute transaction est validée (qui est concerné).
- **Partage équitable** : pour les dépenses/avances validées, chacun consomme sa part (montant ÷ nombre de participants concernés).
- **Solde** : le système calcule qui doit quoi à qui ; la clôture et l’export (si disponible) reprennent ces soldes.

Détails complets : voir **GUIDE_REGLE_BONKONT.md**.

### Qui voit quoi ?

- **Organisateur** : voit tous les événements qu’il a créés + ceux où il est participant.
- **Participant invité** : ne voit que les événements où il est **participant accepté** (pas les événements des autres organisateurs auxquels il n’a pas été invité).

---

## 7. Dépannage rapide

| Problème | À faire |
|----------|--------|
| « Code non trouvé » ou « Code trop court » | Saisir **les 8 lettres** du code (ex. `HTKNDVHT`), puis « Rechercher ». |
| L’événement invité disparaît du tableau de bord | Recharger la page ou rouvrir le tableau de bord ; vérifier que vous êtes bien connecté avec le même compte que pour rejoindre. |
| Je ne vois pas l’événement après avoir rejoint | Attendre que l’organisateur **accepte** votre demande ; ensuite rafraîchir ou rouvrir le tableau de bord. |
| Je ne vois pas mes commits sur GitHub | Aller sur https://github.com/GeorgesCod/BonKont (ou votre dépôt), puis cliquer sur « X commits » pour voir l’historique. |
